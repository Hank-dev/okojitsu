🦧 Designing CLA Games

CLA games are not drills. They are live, resisted situations where both players have a task — and skill emerges from the struggle. The coach's job is to design the environment. The athlete's job is to solve the problem.

The 7-Step Process

1. Identify the invariant — what never changes? 2. Define the problem — put them in the problem, don't explain the solution. 3. Create the win condition — clear, achievable through multiple paths. 4. Set the constraints — task rules, starting position, partner. 5. Keep it live — both resisting, unscripted. 6. Progress the game — add conditions, not techniques. 7. Coach in real time — observe, then adjust.

You can run any of these, but you have to know what to do next based on what just happened. "Next" might be: same game, new partner. Same game, different time. Same game, one changed constraint. The only question that matters: is this challenging enough to create a change?
